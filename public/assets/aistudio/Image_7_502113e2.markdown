## Brand & Style

This design system expresses the personal portfolio of an ambitious, engineering-focused university student. It communicates technical credibility, engineering precision, and architectural discipline. Inspired by high-craft developer platforms such as Linear, Vercel, and GitHub, the aesthetic balances modern dark minimalism with subtle glassmorphic depth.

The interface evokes confidence and capability without unnecessary ornamentation. It signals to recruiters, engineering managers, and collaborators that the creator builds production-grade software with acute attention to detail.

Key design principles:
- **Precision over Decoration:** Every border, glow, and monospace tag serves to anchor visual structure or clarify metadata.
- **Controlled Luminescence:** Deep, matte slate surfaces recede into the canvas, allowing electric blue interactive cues and cyan ambient highlights to guide user focus.
- **Structured Hierarchy:** Code blocks, macOS-style window artifacts, and pill tags reflect genuine technical tooling.

## Colors

The palette relies on a tiered system of deep slates paired with electric blue and cyan accents, calibrated for dark mode.

### Base Surfaces
- **Canvas Base (`#0F172A`):** The foundational viewport background.
- **Card / Surface Default (`#1E293B`):** Structural containers, project cards, and navigation surfaces.
- **Elevated Container (`#334155`):** Modals, flyouts, code chrome headers, and high-emphasis hover states.

### Accent & Feedback
- **Primary Electric Blue (`#2563EB`):** Primary interactive triggers, active links, and brand highlights. Hover transitions shift to `#1D4ED8`.
- **Secondary Cyan Glow (`#38BDF8`):** Subtle ambient badges, focus rings, and high-visibility status tags.
- **Tertiary Mint Success (`#10B981`):** Live demo indicators, availability beacons ("Open to Work"), and status checkmarks.

### Typography & Ink
- **High-Contrast Text (`#F8FAFC`):** Primary headings, active item labels, and emphasized code syntax.
- **Muted Slate Body (`#94A3B8`):** Paragraphs, descriptions, project summaries, and secondary metrics.
- **Subtle Slate Metadata (`#64748B`):** Timestamps, deactivated states, border guides, and footer fine print.
- **Subtle Stroke (`#334155` at 50%â€“70% opacity):** Structural delimiters and component borders.
